# Día 2 — Plan de cierre funcional

## Objetivo
Validar y cerrar el flujo funcional principal:

`Soporte → Instructor → Grupo → Aprendiz → Actividad → Evidencia → Revisión`

## Datos de prueba
Ejecutar `python scripts/day2_seed_demo.py` para crear datos locales de demostración.

## Recorridos
1. Soporte: administración de evidencias.
2. Instructor: grupo y aprendiz asignados.
3. Aprendiz: consulta y entrega de evidencia.
4. Instructor: revisión/observación/aprobación.
5. Soporte: verificación de consistencia y trazabilidad.

## Importante
El script crea únicamente datos de demostración con identificadores `*.demo@gia.local` y ficha `DIA2-3002645`.
No se debe usar como seed de producción.
